Live on Render · Static Site

你好，YG。

这是一个纯静态页面，直接托管在 Render 上：没有服务器、没有运行时、没有构建时长。你现在看到的就是线上产物。

零构建

Build Command 留空，Publish Directory 指向仓库根目录，Render 直接把文件发到 CDN。

全球边缘

静态资源走 Render 的边缘节点，自动签发并续期 TLS 证书。

自动部署

仓库连上后，每次 push 到 main 触发一次重新发布。

自定义域名

Settings → Custom Domains，加一条 CNAME 指向本服务即可。
